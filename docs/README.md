# Project Magic Worlds - Documentation Hub

This folder contains all essential project management documents for the Magic Worlds ecosystem.

## Folder Structure

*   **/Research**: Contains research reports and documentation.
*   **/designs**: All UI/UX mockups, wireframes, and design assets.
*   **/requirements**: Product Requirement Documents (PRDs) and user stories.
*   **/reports**: Stakeholder updates and progress reports.
*   *   **/tech**: All technical documentation, like API documentation and the rest.

Please keep this directory organised and up-to-date.
